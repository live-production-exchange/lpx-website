# LPX Metadata



Below is the reference schema for the DPP Live Production Exchange based on the [IPTC Ninjs (News in JSON) version 3.0](https://iptc.org/standards/ninjs/)

---

##### [Administrative Properties](/schema/administrative/)

The ID, creation, and version details of the content.

##### [Rights Properties](/schema/rights/)

Rights and usage terms for the live event

##### [Event Properties](/schema/events/)

Details for the event the live feed covers

##### [Editorial Properties](/schema/editorial/)

Editorial metadata describing the live event feed that can be shown to an audience.

##### [Rendition Properties](/schema/renditions/)

Technical details about available feeds and how to access them.

##### [JSON Schema](/schema/json/)

DPP LPX JSON schema for exchanging data
