# Introduction to DPP LPX



Live Production Exchange (LPX) is a collaborative project led by the *DPP* together with the International Press Telecommunication Council (IPTC), and leading media companies to develop a common, open framework to bridge the gap between live production producers, broadcasters, and the technology they use.

LPX provides a framework for automating live production workflows. Its aim is to assist both live event publishers and consumers to better realise efficiencies from their investments in cloud based and IP production technologies by introducing a recommended approach in two key areas.

* Firstly, LPX provides a standardised approach to live production metadata that provides both the event characteristics and the technical live IP rendition details.
* Secondly, it provides a metadata schema for machine-to-machine real-time communication about live events
