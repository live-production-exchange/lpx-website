# Reference APIs



While DPP LPX provides a recommendation for automating the exchange of Live Feed data, it does not provide a standard API implementation. The recommendation is designed to help vendors, broadcasters and content producers exchange data in a uniform way via their own API implementations.

Here are some example reference APIs that have implemented DPP LPX that can help with designing your own implementation
