title: LPX Data Model
---





As the below diagram shows, every LPX “liveEvent” object can be used to describe a single event or a series of events.

Each event can be described through the following properties:

* Administrative metadata - describing who produced the event and when it was published
* Rights metadata - describing the copyright, cover rights and usage terms
* Event metadata - describing the event covered by the live feed
* Editorial metadata - describing the details for the live event feed for an audience
* Rendition metadata - describing the technical details for available feeds and how to access them

![](/1.0/introduction/model/data_model.png)

The LPX metadata model and related fields are described in more detail in [LPX Metadata](/1.0/schema/)
