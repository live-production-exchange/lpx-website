# Editorial Properties



Properties representing the editorial metadata describing the live event feed that can be shown to an audience.

| Property | Lvl 2 | Lvl 3 | Type | Description |
| --- | --- | --- | --- | --- |
| genre |  |  | Object | A container for properties related to genre |
|  | name |  | String | A description of the genre of the content |
| headline |  |  | String | Publishable headline for the event |
| language |  |  | String | The human language used by the content |
| location |  |  | String | Place name where event is located |
| slugline |  |  | String | A human-readable identifier for the item |
| topic |  |  | String | Indicates subject of the event |
